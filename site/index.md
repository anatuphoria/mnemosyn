# Mnemosyn

A free 3D atlas of the human central nervous system for students. Turn it, slice it, follow a
pathway through it and test yourself on it. Every shape comes from open, cited research data.

[Download](download.md){ .md-button .md-button--primary } [What is inside](atlas/structures.md){ .md-button }

</div>

<div class="features" markdown>

<div markdown>
:material-rotate-3d-variant:{ .feature-icon }

**Explore in 3D**

Hide, isolate, search and frame any structure in one scene.
</div>

<div markdown>
:material-layers-outline:{ .feature-icon }

**Slices like atlas plates**

Axial, coronal and sagittal sections over an MRI, linked to 3D.
</div>

<div markdown>
:material-map-marker-path:{ .feature-icon }

**Pathways and circuits**

Follow a route station by station, with what a lesion causes.
</div>

<div markdown>
:material-cards-outline:{ .feature-icon }

**Quiz yourself**

Name it, find it and flashcards with spaced repetition.
</div>
